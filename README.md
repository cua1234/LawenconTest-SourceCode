Untuk Menjalankan Test Katalon : 
1. Pull Project berikut pada lokal
2. Set Variabel Pada Testcase
3. Buat Test Suite Baru
4. Tambahkan Test data Excel "testdata.xlsx" dengan cara add New Test data, kemudian import file "testdata.xlsx maka data akan muncul pada layar katalon
5. Tambahkan Testcase pada Test suite
6. Hubungkan (Mapping) Variabel yang sudah di set pada Testcase dengan Testdata yang sudah di impor dengan cara



Untuk Menjalankan Test API : 
1. Buka Postman
2. Export Collection yang sudah diberikan
3. Klik kanan pada collection dan klik run untuk menjalankan keseluruhan
4. Untuk Menjalankan 1 per 1 maka buka per request dan kemudian klik send, maka respon bisa dilihat pada bagian bawah


Spesifikasi : Katalon Studio Enterprise, Java bersi v17.0.12, Newman v6.2.2
